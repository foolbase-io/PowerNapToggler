# PowerNap Toggler 1.0.1 — Free Launch Month

PowerNap Toggler is launching with a free access window through June 8, 2026.

It is a tiny macOS menu bar utility for switching your Mac between:

- **Battery Saver**: turns off Power Nap and TCP keepalive to reduce background wake/network activity.
- **Normal Mode**: turns both settings back on for the usual macOS background behavior.

## What's New

- New glossy dark menu bar control panel.
- Minimal native menu bar icon.
- One primary Battery Saver / Normal Mode switch.
- Clear setting indicators for Power Nap and TCP keepalive.
- Admin permission explanation before applying system changes.
- Verification after changes, so the UI does not blindly assume success.
- Calendar-based launch access, so early downloads do not remain free forever after the launch window ends.
- Runs on-device with no tracking.

## Install

1. Download the DMG or ZIP.
2. Open it.
3. Drag **PowerNap Toggler** into **Applications** if using the DMG, or move the app into Applications if using the ZIP.
4. Launch it from Applications.

If you download the **signed + notarized** ZIP build, macOS should be able to verify it with Gatekeeper (verification may be online because stapling is skipped). If you use an **unsigned** fallback ZIP, macOS may warn that the app is from an unidentified developer.

## Launch Offer

PowerNap Toggler is free through June 8, 2026. Starting June 9, 2026, the app requires the planned one-time paid license to keep switching modes.
