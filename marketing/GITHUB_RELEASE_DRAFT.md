# GitHub Release Draft

## Title

PowerNap Toggler 1.0.0 - Free Launch Month

## Tag

v1.0.0

## Description

PowerNap Toggler is launching free for the first month.

It is a tiny macOS menu bar app that switches your Mac between **Battery Saver** and **Normal Mode** by controlling Power Nap and TCP keepalive.

### Why use it?

- Stop background wake/network behavior when you want your Mac to rest.
- Turn normal background behavior back on when you want your Mac ready and connected.
- Use one compact menu bar control instead of remembering terminal commands.
- Runs on-device.
- No tracking.
- No App Store required.

### What's included

- Glossy dark menu bar control panel.
- Minimal native menu bar icon.
- Battery Saver / Normal Mode switch.
- Power Nap and TCP keepalive status indicators.
- Admin permission explanation before applying changes.
- State verification after changes.

### Install

1. Download `PowerNap-Toggler-Free-Launch-Month.zip`.
2. Unzip it.
3. Move **PowerNap Toggler.app** to Applications.
4. Launch it from Applications.

macOS may warn that the app is from an unidentified developer until signing/notarization is configured.

### Launch offer

PowerNap Toggler is free during launch month. After that, the plan is to move new users to a simple one-time license.
