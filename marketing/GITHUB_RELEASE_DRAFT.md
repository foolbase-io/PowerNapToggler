# GitHub Release Draft

## Title

PowerNap Toggler 1.0.1 - Free Launch Month

## Tag

v1.0.1

## Description

PowerNap Toggler is free through June 8, 2026.

It is a tiny macOS menu bar app that switches your Mac between **Battery Saver** and **Normal Mode** by controlling Power Nap and TCP keepalive.

### Why use it?

- Quiet Power Nap and TCP keepalive behavior when you want your Mac to rest.
- Turn normal background behavior back on when you want your Mac ready and connected.
- Use one compact menu bar control instead of remembering terminal commands.
- Runs on-device.
- No tracking.
- No App Store required.

### What's included

- Glossy dark menu bar control panel.
- Minimal native menu bar icon.
- Battery Saver / Normal Mode switch.
- Power Nap and TCP keepalive status indicators.
- Admin permission explanation before applying changes.
- State verification after changes.

### Install

1. Download `PowerNap-Toggler-Free-Launch-Month-signed.zip` (recommended).
2. Unzip it.
3. Move **PowerNap Toggler.app** to Applications.
4. Launch it from Applications.

If you use the **signed + notarized** ZIP build, macOS should be able to verify it with Gatekeeper (verification may be online because stapling is skipped). If you use an **unsigned** fallback ZIP, macOS may warn that the app is from an unidentified developer.

### Launch offer

PowerNap Toggler is free through June 8, 2026. Starting June 9, 2026, the plan is to require a simple $9 one-time license to keep switching modes.
